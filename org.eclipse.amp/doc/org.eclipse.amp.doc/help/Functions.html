Functions

Functions are relatively simple in terms of model design, but we need to understand how particular functions work in order to develop models. Functions are divided in two ways. By type:

  1. Operators are simple calculations sharing the same type.

  2. Generics that can represent any general function that takes some well-defined input(s) and returns some well-defined output(s).

And by usage:

  1. Functions proper can return any value and are used in Evaluate actions.

  2. Logicals return some boolean result and are used by Query actions to decide wether target Actions apply to a particular selection, and by Evaluate actions just as with any other functions. Input types should be defined as generally as possible.

A technical note: conceptually, functions can return multi-values, but that is not currently implemented in the reference targets because of limitations of the target language Java.
